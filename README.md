# Food_ordering_website

A modern and fully responsive Food Ordering Website built using HTML, CSS, and JavaScript. This project demonstrates frontend development skills including UI design, DOM manipulation, modular JavaScript, and local storage handling.

# Features

* Responsive Navbar with logo, navigation links, and cart icon
* Dynamic Menu Page with category filtering
* Add to Cart functionality 
* Cart data stored using LocalStorage
* Cart & Checkout Page
* Fully responsive design 
* Modern UI with hover effects and animations
